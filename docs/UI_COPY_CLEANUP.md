# 界面文案规范

## 文案约定

- 管理端使用明确的操作名称和中文进度提示，例如“录像导入”“正在导入录像”“等待特征提取”。
- 游客端统一使用“您”，错误提示说明当前状态和下一步操作。
- 普通业务页面不使用“联调”“模拟器”等开发阶段描述。技术部署细节放在部署文档中；设备地址等操作必需信息保留。
- 真实的测试登录、模拟支付继续明确标识测试性质。不得将模拟支付包装为真实付款；真实微信支付仍提示会产生扣款。
- 修改显示文案时同步维护 aria-label、占位符和现有测试定位器。接口路径、状态值、审计事件名和存储分类保持兼容。

## 验证要求

修改界面文案后运行两端类型检查、构建及相关浏览器用例。接口桩测试用于验证页面交互，真实摄像头、邮件和支付另行验收。
